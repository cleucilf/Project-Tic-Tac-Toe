# Networked Tic-Tac-Toe

A real-time two-player Tic-Tac-Toe game built in C that synchronizes gameplay between two devices over MQTT.

The project combines a graphical interface, networking, embedded hardware, and a Linux environment into one system.

## Features

- Real-time two-player gameplay
- MQTT-based communication between endpoints
- Raylib graphical interface
- ESP32 integration
- Modular game logic and message handling
- Git-based version control

## Technologies

- C
- Raylib
- MQTT
- ESP32
- Linux
- Git

## How It Works

The application separates the game interface, game logic, and networking responsibilities while keeping them synchronized through MQTT messages.

Player actions are transmitted between endpoints so both sides maintain the same game state in real time.

## What I Learned

This project helped me understand how multiple systems work together inside one application.

I gained experience integrating networking, embedded hardware, graphical interfaces, and application logic while debugging communication between different components.
